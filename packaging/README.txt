FindAnswer 本地版（Windows 11 x64）

【启动】
1. 解压整个 FindAnswer 文件夹，不要只复制 exe。
2. 双击 FindAnswer.exe，会直接打开 FindAnswer 应用窗口，不需要终端或浏览器。
3. 关闭应用窗口即可退出程序。

【首次使用】
1. 打开左侧「模型连接」。
2. 分别填入硅基流动和 DeepSeek 的 API Key，保存时会自动测试连接。
3. 密钥只保存在当前 Windows 用户的凭据管理器中，不会写入程序文件或浏览器存储。

【资料与数据】
- 支持 TXT、Markdown 和文字型 PDF，单文件不超过 20 MiB。
- 上传的资料保存在 %LOCALAPPDATA%\FindAnswer\data。
- 删除整个数据文件夹即可清空本地资料；删除程序文件夹不会自动删除资料。
- 本版本从空资料库开始，不包含任何示例或旧数据。

【常见问题】
- 界面使用 Windows 11 自带的 WebView2 组件，不需要另外安装浏览器。
- 8000 端口被占用时会自动选择其他端口，不影响使用。
- 重复双击会在任务栏中切回已打开的应用窗口。
- 首次运行可能被杀毒软件询问，请确认来源后允许。
- 本程序只监听 127.0.0.1，不对局域网或互联网开放。
- 启动异常时可查看日志：%LOCALAPPDATA%\FindAnswer\logs\desktop.log
